Shift_calander C조 근무 알람

중요: 미서명 파일이며 실제 아이폰에서 가져오기·동작은 검증되지 않았습니다. 바로 설치되는 완성본이 아닙니다. 서명되지 않은 단축어 가져오기가 지원되지 않는다는 메시지가 나오면 이 파일을 그대로 설치할 수 없습니다.

포함된 내용
- 한국 시간과 C조 기준. 오늘 시작하는 일정의 제목이 C조 주간 / C조 야간으로 시작하는지 확인합니다.
- 주간 06:30, 야간 18:30. 특근·O.T해제 포함. 휴무·연차·반차 제외.
- 이미 지난 시간의 알람은 끕니다.
- 동일 제목을 가진 다른 캘린더 일정도 검색 대상입니다.
- 알람 생성·삭제를 하지 않습니다. 전용 알람 두 개를 먼저 만들어야 합니다.

서명 후 초기 설정
1. 시계 앱에서 반복 없는 Shift_calander 주간(06:30), Shift_calander 야간(18:30)을 만들고 소리를 선택합니다.
2. 가져오기 질문에서 전용 알람 두 개를 각각 지정합니다. 가져오기 질문이 나타나지 않으면 마지막 두 알람 동작의 선택 항목을 직접 지정합니다.
3. Google 근무 캘린더가 아이폰 기본 캘린더에 내려오는지 확인하고 단축어를 실행해 권한을 허용합니다.
4. 단축어 앱의 개인용 자동화에서 매일 00:05 / 즉시 실행 / 이 단축어 실행을 등록합니다. 이 개인용 자동화는 파일에 포함되어 있지 않습니다.
5. 시계 앱에서 상태를 확인하고 잠금 상태 실행과 소리를 실기 검증하세요. 일정 누락·동기화 지연·자동화 실패 시 알람을 보장하지 않습니다.

Mac에서 서명하는 명령(Apple 도구 필요)
shortcuts sign --mode anyone --input Shift_calander_C_unsigned.shortcut --output Shift_calander_C_signed.shortcut

이 파일은 설치 및 실행 검증 전의 구성 파일입니다. 기기·iOS 버전에 따라 알람 동작 재선택이나 수정이 필요할 수 있습니다.
