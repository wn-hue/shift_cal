내 근무에 맞는
알람 단축어

주간은 06:30, 야간은 18:30. 오늘 근무에 맞춰 시계 알람을 켜고, 휴무·연차·반차에는 꺼요. 특근도 같은 시간에 적용됩니다.

01

내 교대조 파일 받기

앱에서 사용하는 교대조의 파일을 선택하세요.

A조단축어 받기 ↓ B조단축어 받기 ↓ C조단축어 받기 ↓

아이폰에서 받은 파일을 열고 단축어 추가를 누르세요. 다운로드 목록이나 파일 앱에 저장됐다면 그곳에서 파일을 열면 됩니다.

맥에서 받았다면 AirDrop으로 아이폰에 보내세요. 기존 근무 알람 자동화는 새 단축어로 바꿔 주세요.

02

전용 알람 두 개 만들기

아이폰 시계 앱에서 아래 이름과 시간으로 각각 하나씩 만드세요. 반복은 안 함, 사운드는 원하는 소리로 설정하고 처음에는 모두 꺼 둡니다.

주간 · 주간 특근06:30Shift_calander 주간
야간 · 야간 특근18:30Shift_calander 야간

이미 이 이름과 시간의 알람이 있다면 그대로 사용하세요. 같은 이름의 알람이 여러 개 있거나 하나라도 없으면 단축어가 안내를 표시하고 멈춥니다.

03

근무 캘린더 연결하고 실행하기

  1. Shift_cal에서 이번 달·다음 달의 캘린더 동기화를 실행합니다.
  2. 아이폰 설정 → 앱 → 캘린더 → 캘린더 계정에서 같은 Google 계정을 추가하고 캘린더를 켭니다.
  3. 아이폰 기본 캘린더에서 내 조의 Shift_calander 캘린더와 오늘 근무가 보이는지 확인합니다.
  4. 추가한 내 조의 Shift_cal 근무 알람을 직접 실행하고 필요한 캘린더·시계 접근을 허용합니다.
  5. 시계 앱에서 오늘 근무에 맞는 전용 알람만 켜졌는지 확인합니다.

Google 캘린더 앱에만 보이는 일정은 읽지 못할 수 있어요. 캘린더와 전용 알람 이름을 바꾸지 말고, 아이폰의 날짜·시간대는 한국 시간 기준으로 설정하세요.

04

매일 자동으로 실행하기

  1. 아이폰 단축어 앱 → 자동화 → + → 특정 시간을 선택합니다.
  2. 00:05 · 매일 · 즉시 실행으로 설정합니다. ‘실행 전에 묻기’가 보이면 끕니다.
  3. 단축어 실행에서 내 조의 Shift_cal 근무 알람을 선택하고 저장합니다.

시간 자동화는 아이폰에서 한 번 직접 등록해야 합니다. 교대조를 바꾸면 새 조의 파일을 추가하고 자동화의 실행 단축어도 바꿔 주세요.

어떤 알람이 켜지나요?

이미 지난 시각의 알람은 끕니다. 선택한 조의 캘린더에서 오늘 시작하는 ‘조 이름’ 근무 일정이 없거나 중복돼도 둘 다 끕니다. O.T해제는 원래 주간·야간에 맞춰 적용합니다.

근무를 변경했다면

앱에서 동기화 → 아이폰 캘린더에 변경 반영 확인 → 단축어 직접 실행 순서로 적용하세요.

파일 서명과 맥의 가져오기 화면은 확인했습니다. 실제 아이폰의 알람 소리·잠금 상태 자동 실행은 확인이 필요해요. 일정 동기화가 늦거나 자동화가 실행되지 않으면 알람이 설정되지 않을 수 있습니다.

사용을 중단할 때는 자동화와 전용 알람 두 개를 모두 꺼 주세요.
