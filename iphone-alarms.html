Shift_calander

아이폰 · 단축어

근무에 맞춰
시계 알람 켜기

오늘의 근무를 확인해 주간은 06:30, 야간은 18:30에 울리도록 설정해요. 특근도 같은 시간에 적용됩니다.

아이폰에서 아래 설정을 한 번 등록해야 합니다. 이 페이지를 열거나 Google에 로그인하는 것만으로 알람이 설정되지는 않아요.

앱에서 사용하는 교대조를 선택하면 아래 일정 조건을 확인할 수 있어요.

01

아이폰 캘린더 연결

앱에서 캘린더 동기화를 먼저 실행하세요. 아이폰 설정 → 앱 → 캘린더 → 캘린더 계정에서 같은 Google 계정을 추가하고 캘린더를 켭니다.

아이폰 캘린더 앱에서 내 조의 Shift_calander 캘린더를 선택하고 오늘의 근무가 보이는지 확인하세요. Google 캘린더 앱에만 보이면 단축어에서 찾지 못할 수 있어요.

이번 달과 다음 달을 앱에서 열어 동기화해 두세요. 아이폰의 날짜·시간대는 한국 시간 기준으로 설정합니다.

02

전용 알람 두 개 만들기

시계 앱 → 알람 → +에서 아래 두 개를 만드세요. 반복은 안 함, 사운드는 원하는 소리로 설정하고 처음에는 모두 꺼 둡니다.

주간 · 주간 특근06:30Shift_calander 주간
야간 · 야간 특근18:30Shift_calander 야간

기존 개인 알람은 그대로 두고 이 두 개만 사용합니다. 이름이 같은 알람을 여러 개 만들지 마세요.

03

근무 확인 단축어 만들기

단축어 앱 → +에서 새 단축어를 만들고 이름을 Shift_calander 근무 알람으로 지정하세요. 동작 이름과 표시 위치는 iOS 버전에 따라 다를 수 있어요.

먼저 현재 시각 준비하기
  1. 날짜 동작을 추가하고 ‘현재 날짜’를 선택합니다.
  2. 날짜 포맷 지정에서 포맷을 ‘사용자 설정’, 문자열을 HHmm으로 설정합니다. 날짜 입력은 위의 현재 날짜를 선택합니다.
  3. 입력에서 숫자 가져오기로 포맷 지정한 날짜를 숫자로 바꿉니다.
  4. 변수 설정으로 이 숫자를 현재시각에 저장합니다. 예: 06:29는 629, 18:30은 1830입니다.

주간 조건

‘캘린더 이벤트 찾기’를 추가하고 다음 조건을 모두 만족하도록 설정하세요.

캘린더
내 조의 Shift_calander 캘린더
시작일
오늘
제목
조 선택 필요 으로 시작
  1. 조건문: 찾은 ‘캘린더 이벤트’에 값이 있는 경우.
  2. 그 안에 조건문을 하나 더 추가: 변수 현재시각이 630보다 작은 경우 → ‘알람 전환’에서 Shift_calander 주간 켜기. 그렇지 않은 경우 → 같은 알람 끄기.
  3. 첫 번째 조건문의 ‘그렇지 않은 경우’에도 Shift_calander 주간 끄기를 넣습니다.

야간 조건

주간 조건문이 완전히 끝난 뒤 ‘캘린더 이벤트 찾기’를 새로 추가하세요.

캘린더
내 조의 Shift_calander 캘린더
시작일
오늘
제목
조 선택 필요 으로 시작
  1. 조건문: 이번에 찾은 ‘캘린더 이벤트’에 값이 있는 경우.
  2. 그 안에 조건문: 현재시각이 1830보다 작은 경우 → Shift_calander 야간 켜기. 그렇지 않은 경우 → 같은 알람 끄기.
  3. 첫 번째 조건문의 ‘그렇지 않은 경우’에도 Shift_calander 야간 끄기를 넣습니다.
알람 동작은 상태를 반대로 바꾸는 ‘전환’이 아닌 켜기 / 끄기로 지정하세요. 시작일 ‘오늘’을 사용해야 전날 시작한 야간 근무를 오늘 근무로 잘못 읽지 않습니다. 지난 시간의 알람은 꺼지도록 구성합니다.
04

매일 자동으로 실행

  1. 단축어 앱 → 자동화 → + → 특정 시간.
  2. 00:05 · 매일 · 즉시 실행으로 설정합니다. ‘실행 전에 묻기’가 보이는 버전은 이를 끕니다.
  3. 단축어 실행에서 ‘Shift_calander 근무 알람’을 선택하고 저장합니다.

처음에는 단축어를 직접 실행해 캘린더·시계 접근 요청을 허용하세요. 자동화의 실행 알림을 켜 두면 실행 여부를 확인하기 편해요.

05

적용 확인하기

단축어를 실행한 뒤 시계 앱에서 확인하세요. 앱에는 아이폰 알람 상태가 표시되지 않습니다.

오늘 근무시간이 지나기 전
주간 · 주간 특근06:30만 켜짐
야간 · 야간 특근18:30만 켜짐
휴무 · 연차 · 반차 · 무급 휴무둘 다 꺼짐

O.T해제는 원래 주간·야간 시간에 적용됩니다. 반차·개인 일정은 자동 알람 대상에서 제외하며 필요한 알람을 따로 설정하세요.

근무를 변경했다면

앱 캘린더 동기화 → 아이폰 캘린더에 변경 반영 확인 → 단축어 직접 실행 순서로 적용하세요. 교대조를 바꾸면 단축어의 캘린더와 제목 조건 두 개도 변경해야 합니다.

일정이 아직 내려오지 않았거나 자동화 실행에 실패하면 원하는 알람이 설정되지 않을 수 있어요. 실제 아이폰에서 잠금 상태의 자동 실행과 소리를 확인한 뒤 사용하세요. 사용을 중단할 때는 자동화와 전용 알람 두 개를 모두 꺼 주세요.
