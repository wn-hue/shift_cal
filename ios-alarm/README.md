# Shift_cal · iPhone 앱

SwiftUI와 AlarmKit을 사용하는 iOS 26 이상용 앱입니다. 네이티브 근무표와 알람은 오프라인에서 동작하며 계정이나 단축어를 요구하지 않습니다.

## 구현한 기능

- A·B·C조 월간 근무표, 오늘 근무, 월별 근무·연차·휴무 집계
- 날짜별 주간·야간·특근·연차·반차·무급·O.T 해제 변경과 메모
- 조별 변경/메모 저장, 재실행 유지, JSON 백업 및 확인 후 복원
- 이번 달 근무표를 ICS 파일로 내보내기
- 내 근무표 또는 iPhone 캘린더를 출처로 앞으로 30일의 근무 알람 예약
- 주간/주특 06:30, 야간/야특 18:30, 한국 시간 고정; 반차 알람은 별도 선택
- 근무 변경, 조 변경, 알람 끄기, 캘린더 변경에 따라 앱의 예약 갱신/취소
- 1분 뒤 테스트 알람, 예약 목록/마지막 예약일/갱신 실패 표시
- 기존 급여·식단·Google 동기화는 설정의 링크를 통해 Safari에서 사용

앱의 변경과 메모는 웹 계정과 자동 동기화되지 않습니다. 웹의 Google 근무표로 알람을 쓰려면 iPhone에 같은 Google 캘린더를 연결하고 알람 출처를 iPhone 캘린더로 선택합니다. 앱 내 캘린더와 Google 캘린더는 별개의 출처입니다.

웹의 교대 엔진에서 규칙을 추출했습니다. 2025–2027년 A/B/C조 전체 3,285개 날짜를 비교하는 테스트가 포함됩니다. 회사 휴무일에는 교대 주기가 일시 정지하며, 알려진 공휴일에는 주간/야간 특근으로 표시됩니다. 2028년 이후 새로운 회사 휴무·공휴일은 아직 반영되지 않아 기본 교대 주기만 적용합니다.

## 처음 사용하기

1. 근무표에서 본인의 조를 선택합니다.
2. 날짜를 눌러 연차·특근 등 실제 변경을 반영합니다.
3. 알람 탭에서 ‘앱의 내 근무표’를 선택하고 자동 알람을 켜 권한을 허용합니다.
4. 예약 목록과 마지막 날짜를 확인합니다.
5. 1분 뒤 테스트 알람으로 실제 iPhone의 소리·잠금화면을 확인합니다.

시계 앱에서 알람 두 개를 만들거나 매일 00:05 단축어 자동화를 만들 필요가 없습니다. AlarmKit의 앱 전용 시스템 알람이며 기본 시계 목록에 표시되는 알람은 아닙니다.

예약된 알람은 앱 종료 후에도 시스템에서 실행합니다. 30일 이후 예약과 캘린더 변경 반영은 앱 실행 또는 iOS가 허용한 백그라운드 갱신이 필요합니다. 백그라운드 실행 시점은 보장되지 않습니다. 예약 마지막 날짜 전에 앱을 다시 열고, 근무 변경 후 예약 상태를 확인하세요. 캘린더에 주간/야간/연차가 충돌하는 날짜는 알람을 예약하지 않습니다.

## 프로젝트 열기와 빌드

저장소에서는 XcodeGen 2.46 이상으로 프로젝트를 생성합니다. 전달된 프로젝트 ZIP에는 생성된 Xcode 프로젝트도 포함되어 추가 설치 없이 열 수 있습니다.

```sh
cd ios-alarm
xcodegen generate
open ShiftCalAlarms.xcodeproj
```

Xcode의 ShiftCalAlarms 스킴을 선택해 iPhone 시뮬레이터에서 Run합니다. 실기기 설치는 Signing & Capabilities에 본인의 개발팀을 선택해야 합니다. 현재 기본 번들 ID는 `com.wnhue.shiftcal.alarms`입니다. 배포팀에서 사용 가능한 고유 ID인지 확인하세요.

```sh
xcodebuild -project ShiftCalAlarms.xcodeproj -scheme ShiftCalAlarms \
  -destination 'platform=iOS Simulator,name=iPhone 18 Pro' CODE_SIGNING_ALLOWED=NO test
xcodebuild -project ShiftCalAlarms.xcodeproj -scheme ShiftCalAlarms \
  -configuration Release -destination 'generic/platform=iOS' \
  -archivePath Shift_cal.xcarchive CODE_SIGNING_ALLOWED=NO archive
```

서명 없는 archive는 컴파일을 검증하기 위한 결과입니다. 아이폰에 설치하거나 App Store로 업로드할 수 있는 IPA가 아닙니다. 개발팀을 지정한 뒤 서명된 archive를 다시 생성해야 합니다.

웹 규칙을 변경했다면 저장소 루트에서 `node scripts/export-ios-rules.cjs`를 실행해 앱 규칙과 웹 비교 테스트 데이터를 갱신하고 테스트합니다.

## 배포 준비 자료

`Release/AppStore-ko.md`: 앱 설명, 심사 참고 사항, 개인정보 응답 초안.
`Release/Device-QA.md`: 실제 iPhone 검사와 서명/배포에 남은 항목.
`Sources/PrivacyInfo.xcprivacy`: 광고/추적/외부 수집 없음과 UserDefaults 사용 목적 선언.

앱에는 회원 가입, 광고, 분석 SDK가 없습니다. 권한은 알람 활성화 및 iPhone 캘린더 출처를 선택하는 시점에만 요청합니다. 내보내기·백업 공유는 사용자가 직접 대상을 선택합니다.

## 화면 개선 (2026-10-10)

근무표 왼쪽 위 햄버거 메뉴 → 맨 위 교대조 설정에서 A/B/C조를 변경합니다. 근무표·공유·알람·설정의 네 탭을 사용합니다. 근무표는 흰 바탕·얇은 구분선·작은 근무 약자로 표시하고 날짜를 눌러 근무/메모를 편집합니다. 공유 탭은 선택한 조·월의 PNG 이미지와 ICS 파일을 내보내며 메모는 기본 제외입니다. 메모 포함을 켠 경우 선택한 달의 메모를 포함합니다. 이미지 공유 전에 미리보기에서 확인할 수 있습니다. 링크/동료 그룹을 만드는 온라인 공유 기능은 포함하지 않습니다.

### 미니멀 UI 조정

큰 오늘 근무 카드와 날짜별 카드 배경을 제거하고 월간 달력이 화면 높이에 맞게 펼쳐집니다. 공유 메뉴는 구분선으로 나눈 목록이며, 근무 편집은 작은 선택 버튼과 밑줄 탭을 사용하고 상단 저장 버튼으로 확정합니다.

근무표·공유 이미지·근무 선택에 같은 진한 색상을 사용합니다. iOS 상단 Google 로그인은 작은 준비 중 표시이며 인증 기능은 아직 구현하지 않았습니다.
