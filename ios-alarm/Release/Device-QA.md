# 실제 iPhone 확인 및 배포 전 남은 단계

코드 컴파일·시뮬레이터 검증과 실제 알람 소리 검증은 별개입니다. 아래 항목은 아이폰을 연결하고 서명된 앱을 설치한 뒤 확인합니다.

## 실기기 확인

- [ ] 알람 권한 거절 → 안내 확인 → 설정에서 허용 → 예약 갱신
- [ ] 1분 뒤 테스트 알람, 잠금화면 소리와 알람 해제
- [ ] 무음·집중 모드에서 실제 알람 동작
- [ ] 앱 종료·아이폰 재부팅 후 예약된 알람 동작
- [ ] 주간·야간·특근 시간과 한국 시간대 확인
- [ ] 연차·휴무로 변경하면 기존 알람 취소
- [ ] 주간↔야간 및 C↔A↔B 조 변경 시 이전 예약 정리
- [ ] 자동 알람 끄기 시 테스트 알람 포함 이 앱의 예약 취소
- [ ] 반차 기본 제외 및 선택 시 기존 근무 시각 적용
- [ ] Google 캘린더 출처의 동기화/권한 변경/일정 충돌 처리
- [ ] 예약 한도·백그라운드 제한·갱신 실패 표시
- [ ] 다른 시간대로 이동했을 때 한국 시각 유지
- [ ] 작은 화면·큰 글씨·다크 모드·VoiceOver 확인
- [ ] ICS 공유, JSON 백업/복원, 잘못된 백업 거부

## 서명 및 등록

- [ ] Xcode → Settings → Accounts에서 개발자 계정 준비
- [ ] Signing & Capabilities에서 배포팀과 Bundle ID 선택
- [ ] 서명된 Release archive 생성 및 Organizer Validate
- [ ] 지원 연락처/URL 및 공개 네이티브 개인정보 정책 확정
- [ ] App Store 메타데이터·스크린샷·연령 등급 검토

현재 맥의 코드 서명 인증서는 0개이며 연결된 실제 iPhone은 확인되지 않았습니다. 제공된 서명 없는 archive는 직접 설치/업로드할 수 없습니다. TestFlight 업로드와 App Store 심사 제출은 아직 하지 않았습니다.

## 무료 Apple ID로 본인 아이폰 설치

Xcode Settings → Accounts에서 Apple ID를 추가하고, 프로젝트 Signing & Capabilities에서 Personal Team을 선택합니다. 아이폰을 USB로 연결하고 개발자 모드 및 기기 신뢰를 확인한 뒤 Run합니다. 로그인·계약 동의·기기 인증은 본인이 처리합니다. 무료 프로비저닝은 7일 뒤 만료돼 다시 빌드/설치해야 하므로 계속 사용하는 근무 알람의 정식 배포 대체 수단은 아닙니다.

Apple 공식 안내: https://developer.apple.com/help/account/basics/about-your-developer-account
