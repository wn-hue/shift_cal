연차·상여금 계산 기준

입사 날짜는 정규직 전환일을 입력해 주세요. 급여 기간 마지막 날(15일) 기준 정규직 1년 미만은 지원금, 1년부터는 상여금이 적용됩니다. 연차도 정규직 전환일부터 계산합니다. 1년 미만은 매월 개근 시 1일씩 최대 11일, 다음 해 1월 1일에는 전년도 재직기간에 비례한 연차를 별도로 추정합니다. 월별 발생분의 미사용분은 첫 1년 종료 시 소멸하며 사용 내역은 월별 발생분부터 차감합니다. 개근과 회계연도 부여를 가정한 추정값이므로 회사에서 확인한 총 연차로 조정할 수 있습니다.

시급 설정

급여 문자로 가져오거나 시급을 직접 입력해 주세요.

시급·고정수당과 지급·공제 내역을 자동 인식합니다.

상여금은 기존 지급 기준으로 계산합니다. 개인 공제율을 적용하려는 경우에만 문자를 입력하세요.

이름·사번·계좌번호는 제외해 주세요. 원문은 기기에서만 인식하고 적용·닫기 시 지웁니다. 저장 항목은 시급·통상시급·고정수당 합계와 공제 기준입니다. 급여 법정요율 항목이 인식되면 월 보험료·기타 월 공제액과 세금·고용 비율을 저장합니다. 지급·공제 합계는 저장하지 않습니다. 로그인하여 동기화를 연결하면 저장 항목도 본인 계정에 전송됩니다. 저장 안내

어떤 항목이 적용되나요?

급여문자 확인에서 시급과 자격·직무·가족·직책 줄을 붙여넣으세요. 인식한 네 수당의 합계를 고정수당으로 적용합니다. 수당을 바꿀 때는 해당되는 네 항목을 함께 붙여넣어 주세요. 공제율은 선택 사항이며 지급 합계·공제 합계 두 줄로 계산합니다. 상여 문자에서는 상여금 공제율만 적용하며 시급·수당은 바꾸지 않습니다. 비워둔 칸의 기존 설정은 유지됩니다. 급여의 연금·건강·고용에 법정요율이 표시되고 세금 내역이 있으면, 연금·건강(별도 요양 포함)은 문자 월액으로 유지하고 고용은 문자와 일치하는 0.9% 또는 문자 비율로 추정합니다. 소득세·지방소득세는 문자 비율로 추정합니다. 기타 공제는 문자 월액으로 유지합니다. 해당 내역이 없으면 공제 합계 ÷ 지급 합계로 추정합니다. 상여금은 상여 문자 공제율만 사용하므로 급여 월 보험료를 다시 차감하지 않습니다. 보험료 정산·비과세·가족 수 변경 시 새 문자를 적용하세요. 비워둔 문자 칸의 기존 공제율은 변경하지 않습니다. 저장된 공제율이 없으면 세후 추정 화면은 기본 공제율 18%를 사용합니다. 이는 개인별 세금·보험료를 정확히 계산한 값이 아닙니다. 상여 문자만으로 급여 공제율을 추정하지 않습니다. 상여 지급액·근무일수 계산은 기존 규칙을 유지하며 추정 공제액은 실제 세액과 다를 수 있습니다.

급여명세서에 적힌 두 시급을 입력해 주세요.

시급만 변경되며 기존 수당과 공제 기준은 유지돼요. 문자 공제 기준이 없으면 세후 금액은 기본 공제율 18%로 단순 추정해요. 개인별 세금·보험료와는 차이가 있어요.

동기화 상태 확인 중…

구글 전용 캘린더에 근무표·메모·개인 일정을 저장합니다. 앱 변경은 저장 후 반영하고, 구글·아이폰에서 바꾼 내용은 앱을 열면 가져옵니다. 열린 동안에는 약 30초마다 확인합니다.

계정 확인, 캘린더 목록 조회와 앱이 만든 캘린더의 일정 관리 권한을 요청합니다. 개인정보 이용·삭제 안내

동기화 관리

중지·해제해도 구글에 저장된 일정은 남습니다. Google 계정의 앱 권한을 완전히 취소하려면 Google 계정 → 보안 → 연결된 앱에서 해제하세요.

관리자 최초 설정

Google Cloud에서 Calendar API를 켜고 웹 애플리케이션 OAuth 클라이언트를 만드세요. 개인 테스트에서는 본인 이메일을 테스트 사용자로 등록합니다.

승인된 리디렉션 URI:

Vercel 프로젝트에 GOOGLE_CALENDAR_CLIENT_ID, GOOGLE_CALENDAR_CLIENT_SECRET, GOOGLE_CALENDAR_SESSION_SECRET(32자 이상 무작위 값), APP_URL(앱의 https 주소)을 등록하고 재배포하세요. 비밀 키는 코드·채팅에 붙여 넣지 마세요.

아이폰 기본 캘린더에서 사용하기

근무 종류를 구글에서 바꿀 때는 제목을 연차, 반차(전), 반차(후), 주간 특근, 야간 특근 등으로 지정하세요. 근태 변경·동시 수정·근무표 삭제는 앱에서 확인한 뒤 적용합니다. 단순 메모 변경과 개인 일정은 자동으로 가져옵니다.

동기화를 누르면 현재 보고 있는 달의 근무표를 반영합니다. 이후 다른 달을 열면 그 달도 자동으로 동기화합니다. 개인 일정은 Google 또는 아이폰 기본 캘린더의 앱 전용 캘린더에서 추가할 수 있습니다.
