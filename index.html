Google 캘린더에 근무표 보내기

연결 상태를 확인하고 있어요…

근무표와 날짜 메모를 Google 캘린더에 보내요. 다시 보내면 근무 루틴에 저장한 내용으로 바뀌니, 수정은 근무 루틴에서 해 주세요. 저장한 기록은 Google Drive에서 불러올 수 있어요.

근무표 보내기는 원하는 분만 연결하면 돼요. 연결할 때 캘린더 목록을 보고 근무 루틴 전용 캘린더의 일정을 관리할 수 있도록 권한을 요청해요. 개인정보 이용·삭제 안내

보내기 관리

보내기를 중지하거나 연결을 끊어도 이미 보낸 근무표는 남아요. 앱 권한은 Google 계정의 보안 → 연결된 앱에서 해제할 수 있어요.

관리자 최초 설정

Google Cloud에서 Calendar API를 켜고 웹 애플리케이션 OAuth 클라이언트를 만드세요. 개인 테스트에서는 본인 이메일을 테스트 사용자로 등록합니다.

승인된 리디렉션 URI:

Vercel 프로젝트에 GOOGLE_CALENDAR_CLIENT_ID, GOOGLE_CALENDAR_CLIENT_SECRET, GOOGLE_CALENDAR_SESSION_SECRET(32자 이상 무작위 값), APP_URL(앱의 https 주소)을 등록하고 재배포하세요. 비밀 키는 코드·채팅에 붙여 넣지 마세요.

설정 순서 자세히 보기
아이폰 기본 캘린더에서 사용하기

아이폰 설정 → 앱 → 캘린더 → 캘린더 계정 → 계정 추가 → Google에서 같은 계정을 연결하고 캘린더를 켜세요. 기본 캘린더 앱에서 앱 전용 A/B/C조 캘린더를 선택하면 보낸 근무표가 표시됩니다.

근무표나 메모를 바꿀 때는 근무 루틴에서 수정해 주세요. 지금 보고 있는 달의 근무표를 보낼 수 있어요. 자동 보내기를 켜면 내용을 수정하거나 다른 달을 열 때 해당 달의 근무표도 보내요.
