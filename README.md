# 교대근무 앱

교대 일정, 연차와 예상 급여를 휴대폰에서 확인하는 설치형 웹앱입니다.

## 앱 설치

GitHub Pages 주소를 휴대폰에서 연 뒤 설치합니다.

- 안드로이드: 화면 위의 `앱 설치` 버튼 또는 브라우저 메뉴의 `앱 설치`
- 아이폰·아이패드: Safari 공유 버튼 → `홈 화면에 추가`

설치 후에는 인터넷 연결이 없어도 마지막으로 내려받은 앱을 열 수 있습니다.

## 자료 보관

입력한 자료는 사용 중인 기기의 브라우저에만 저장됩니다. `연차 & 설정` 화면의 `백업 저장`으로 파일을 내려받아 보관할 수 있습니다.

급여와 연차 계산 결과는 예상값입니다. 실제 지급액과 적용 규정은 회사 급여명세서와 담당 부서에서 확인해야 합니다.
