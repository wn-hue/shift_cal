# Shift_cal 캘린더 연결

## 구글 계정 저장

**왼쪽 상단 메뉴 → Google로 로그인**에서 로그인하면 근무 변경·메모·연차·급여 설정을 같은 Google 계정의 다른 기기에서 불러옵니다. 운영자는 기존 OAuth 프로젝트의 Google Drive API를 사용 설정하고 앱 전용 저장 범위를 추가해야 합니다. [설정 및 동기화 안내](GOOGLE_ACCOUNT_STORAGE.md)를 확인하세요.

## 표시 및 개인정보 처리

- Google 근무 일정은 주간 노랑(5), 야간 파랑(9), 휴무 회색(8), 연차 연두(2)로 표시합니다. 앱이 열려 있으면 이 기기에 연결 기록이 있는 기존 일정의 색상을 순서대로 갱신합니다. 색상만 바꾸는 요청은 제목·메모·근태를 덮어쓰지 않으며 ETag 충돌 검사도 적용합니다. 이동/삭제/인식 불가 일정은 보존하고, 개인 일정에는 이 색상 갱신을 적용하지 않습니다.
- 기타지급액은 입사일로 자동 판단합니다. 해당 금액이 없으면 지급 상세 행을 숨깁니다. 기존 수동 적용 플래그는 계산에 사용하지 않습니다.
- 기본시급·통상시급·직책수당·근속수당 입력은 읽기 전용이며 급여 문자 인식·확인·적용으로 설정합니다. 입력 저장 버튼은 시급·수당 입력 DOM 값을 읽지 않습니다. 월 기준시간은 화면에서 숨기고 기존 계산 기준을 유지합니다. 직책·근속수당은 각각 금액이 있을 때만 설정 화면에 표시합니다. 사용자가 제공한 문자의 발급처·진위를 인증하는 기능은 아닙니다.
- 실수령액 OFF가 기본입니다. ON이면 상단·지급 상세 합계·급여 안내 금액을 세후 추정으로 표시하고 상세내역에 예상 공제 행을 추가합니다. 계산 원본은 세전 금액으로 유지하므로 중복 차감하지 않습니다.
- 문자 원문·이름·사번은 저장 API로 보내지 않습니다. 원문과 미리보기는 창을 닫거나 계정을 전환할 때 지웁니다. 적용한 금액은 선택한 기기/계정 저장 방식에 따라 보관합니다. [데이터 처리 안내](privacy.html)를 제공합니다.

프런트엔드 계산식과 이 저장소의 코드에는 회사 급여 규칙이 포함될 수 있습니다. 화면 문구를 줄이거나 개인정보 저장소를 분리하는 것만으로 계산 규칙이 비공개가 되지는 않습니다. 이 프로젝트는 법적 적합성, 회사의 외부 공개 승인 또는 문자 진위를 보증하지 않습니다.

## 구글 중심 양방향 연동 (v2)

구글 OAuth 로그인, 앱 전용 캘린더, 근무표·메모 양방향 비교, 근태 변경 확인, 개인 일정 생성·수정·삭제를 지원합니다. 아이폰 기본 캘린더에는 같은 Google 계정의 `Shift_cal A/B/C조`를 연결합니다. 운영자가 Google OAuth 및 Vercel 환경변수를 등록해야 실제 계정 연결을 시작할 수 있습니다. [최초 설정 안내](GOOGLE_CALENDAR_SETUP.md)를 먼저 확인하세요.

구글과 앱 사이의 변경 확인은 브라우저가 열려 있을 때 수행합니다. 기존 localStorage 근태·급여 계산은 유지하며, 외부 근태 변경 및 충돌은 확인 후 반영합니다.

앱 상단 연결 아이콘 또는 왼쪽 메뉴의 **구글 · 애플 캘린더 연결**을 누릅니다. 앱의 읽기 전용 구독 및 ICS 다운로드 화면은 제거했습니다. 근무 변경은 구글 동기화를 사용합니다. 기존에 가져온 파일의 일정이나 구독은 자동으로 삭제하지 않으므로 중복이 있다면 해당 캘린더에서 정리하세요.

## 개발 및 검증

```sh
node scripts/build-calendars.cjs
node scripts/test-calendars.cjs
```

레거시 구독 파일을 유지보수해야 하는 경우에만 위 명령을 사용합니다. 앱 UI에서는 구독·다운로드를 제공하지 않습니다. 구독 파일은 `index.html`의 실제 `getActualShift()`와 `getBaseShift()`를 실행해 만듭니다. 회사 휴무일에는 교대 주기를 멈추는 규칙 및 공휴일 특근 표시도 일치합니다. 2025년부터 앱에 마지막으로 등록된 공휴일/회사 휴무일의 연도까지는 정확한 날짜를 RDATE로 기록하고, 그 다음 연도부터는 12일 반복 일정으로 표시합니다. 미래 회사 휴무나 교대 변경을 새로 등록했다면 위 빌드 명령을 실행하고 `calendars/*.ics`도 함께 커밋해야 합니다. 아직 앱에 등록되지 않은 미래 휴무는 예측하지 않습니다.

읽기 전용 ICS 구독 자체는 개인 변경의 자동 동기화 및 역방향 동기화를 지원하지 않습니다. 구글 양방향 연동을 사용할 때에는 위 v2 기능으로 연결하세요.

공식 안내: [Google Calendar 구독](https://support.google.com/calendar/answer/37100?hl=ko), [Apple 캘린더 구독](https://support.apple.com/ko-kr/102301).
# 아이폰 시계 알람 · 단축어

앱의 전체 메뉴 → **아이폰 근무 알람 · 단축어 설정**에서 조별 설정 안내를 확인합니다.
`iphone-alarms.html`은 설치 파일이 아닌 아이폰에서 직접 등록하는 안내입니다.
아이폰 캘린더에 동기화된 앱 전용 캘린더의 **시작일 오늘 + 제목 접두사**로 주간·야간(특근 포함)을 판별합니다.
시계 앱의 반복 없는 전용 알람 두 개(06:30 / 18:30)를 명시적으로 켜거나 끄며, 지난 시각의 알람은 끕니다.
매일 00:05 개인용 자동화로 실행하도록 등록합니다. 반차·휴무·연차·개인 일정은 제외합니다.
근무 변경 후 캘린더 반영 확인과 수동 단축어 실행이 필요합니다. 실제 기기의 권한, 잠금 상태 실행 및 알람 소리는 사용자가 확인해야 합니다.
