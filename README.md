# Shift_cal 캘린더 연결

웹앱의 달력 아래 **구글 · 애플 캘린더 연결**을 누릅니다.

## 기본 근무표 구독

- 애플: **애플 캘린더 구독**을 누르거나 기본 캘린더 → 캘린더 → 캘린더 추가 → 구독 캘린더 추가에 주소를 붙여 넣습니다. iCloud를 선택하면 같은 계정의 다른 기기에서도 볼 수 있습니다. 홈 화면 웹앱에서 버튼이 열리지 않으면 Safari로 엽니다.
- 구글: 컴퓨터 웹브라우저에서 Google Calendar → 설정 → 캘린더 추가 → URL로 추가에 주소를 붙여 넣습니다. 이후 휴대폰 앱에서도 표시됩니다.
- A/B/C조마다 별도 주소가 있습니다. 조를 변경하면 새 조를 구독하고 이전 구독을 해제합니다.
- 일정은 종일 표시하며 야간은 근무 시작일에 표시합니다. 출퇴근 시간을 지정하지 않습니다.
- 기본 구독은 읽기 전용입니다. 개인 연차·반차·특근·O.T 해제·메모는 포함하지 않습니다. 각 캘린더 서비스의 갱신 주기에 따라 변경 반영이 지연될 수 있습니다.

| 조 | 구독 주소 |
| --- | --- |
| A | https://raw.githubusercontent.com/wn-hue/shift_cal/main/calendars/A.ics |
| B | https://raw.githubusercontent.com/wn-hue/shift_cal/main/calendars/B.ics |
| C | https://raw.githubusercontent.com/wn-hue/shift_cal/main/calendars/C.ics |

## 개인 변경 포함

연동 창에서 기간을 선택하고 **내 일정 파일(ICS) 만들기**를 누릅니다. 현재 선택한 조의 실제 일정 계산 결과를 사용합니다. 휴무와 저장된 메모의 포함 여부를 선택할 수 있습니다. 개인 메모는 기본적으로 제외되며 공개 구독 파일에 전송하지 않습니다.

- 구글: 컴퓨터에서 설정 → 가져오기/내보내기 → ICS 파일 선택 → 대상 캘린더 선택 → 가져오기.
- 애플: ICS 첨부파일을 Mail에서 열거나 Mac 캘린더의 파일 → 가져오기 이용. iOS의 브라우저 다운로드에서 바로 가져오기를 지원하지 않으면 메일 첨부 또는 Mac 경로를 이용합니다.
- 날짜를 누르면 저장된 하루 일정의 구글 추가 화면을 열거나 ICS 파일을 만들 수 있습니다. 구글 추가 화면에서 저장을 완료해야 일정이 추가됩니다.
- 파일 가져오기는 한 번의 복사입니다. 이후 웹앱의 변경을 자동 반영하지 않습니다. 반복 가져오기 또는 기본 구독과 함께 표시할 때 일정이 중복될 수 있으므로 개인 일정용 별도 캘린더에 가져오고 재가져오기 전에 기존 일정을 정리합니다.

## 개발 및 검증

```sh
node scripts/build-calendars.cjs
node scripts/test-calendars.cjs
```

구독 파일은 `index.html`의 실제 `getActualShift()`와 `getBaseShift()`를 실행해 만듭니다. 회사 휴무일에는 교대 주기를 멈추는 규칙 및 공휴일 특근 표시도 일치합니다. 2025년부터 앱에 마지막으로 등록된 공휴일/회사 휴무일의 연도까지는 정확한 날짜를 RDATE로 기록하고, 그 다음 연도부터는 12일 반복 일정으로 표시합니다. 미래 회사 휴무나 교대 변경을 새로 등록했다면 위 빌드 명령을 실행하고 `calendars/*.ics`도 함께 커밋해야 합니다. 아직 앱에 등록되지 않은 미래 휴무는 예측하지 않습니다.

개인 근태와 메모는 기존 브라우저 localStorage에 남습니다. 서버 저장소나 계정 인증은 추가하지 않았습니다. 개인 변경의 자동 동기화 및 캘린더에서 웹앱으로의 역방향 동기화는 현재 지원하지 않습니다.

공식 안내: [Google Calendar 구독](https://support.google.com/calendar/answer/37100?hl=ko), [Apple 캘린더 구독](https://support.apple.com/ko-kr/102301).
