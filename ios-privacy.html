기기에 저장하는 정보

앱 안의 웹 화면(WKWebView)은 선택한 근무조, 근무 변경, 메모, 시급·연차 설정과 표시 설정을 이 기기에 저장합니다. 로그인 상태는 앱 안의 웹 저장소에 있는 HttpOnly·Secure 쿠키로 유지합니다. 알람 설정과 예약에 필요한 근무표 정보는 앱의 기기 저장 공간에 보관합니다. 앱에는 광고·분석·추적 SDK가 포함되어 있지 않습니다.

계정 동기화

로그인은 선택 사항입니다. 로그인하면 제공자가 전달한 계정 식별자와 이메일을 확인합니다. Google 저장을 연결하면 근무 변경, 메모, 급여 기준과 연차 설정을 Google Drive의 앱 전용 공간에 저장하며 일반 Drive 파일은 읽지 않습니다. Apple 로그인이 제공되는 경우 Apple 계정의 데이터는 접근이 제한된 서버 저장소에 보관합니다. 두 제공자의 계정은 자동으로 합쳐지지 않습니다. 일반 로그아웃 후에는 계정에 저장한 데이터와 기기의 계정별 복원용 사본이 유지됩니다.

근무표와 알람 권한

근무표는 앱 안에서 계산하며 iPhone 캘린더 일정에 접근하지 않습니다. 근무조와 날짜별 근무 종류, 공휴일 여부를 앱 안의 웹 화면에서 전달받아 앞으로 30일 범위의 알람을 예약합니다. 자정을 넘기는 야간 알람에는 전날 근무 정보도 사용합니다. 알람을 켤 때 AlarmKit 권한을 요청하며, 권한을 허용하면 iPhone에 알람을 예약합니다. 권한을 거절해도 근무표는 볼 수 있습니다. Google 캘린더로 근무표 보내기는 별도 연결이 필요한 선택 기능입니다. 관련 데이터 처리는 웹 개인정보 처리방침에서 확인할 수 있습니다.

이메일 문의로 받는 정보

문의자가 직접 이메일을 보내면 발신 이메일 주소, 제공한 이름, 문의 내용과 직접 첨부한 파일을 받습니다. 답변, 문제 해결 및 개인정보 요청 처리에만 사용하며 광고에 사용하지 않습니다. 앱은 문의를 자동 전송하거나 근무표·메모·기기 정보를 자동 첨부하지 않습니다. 비밀번호, 인증번호, 급여 명세서 또는 다른 사람의 개인정보를 보내지 마세요. 화면을 첨부할 때 개인 정보를 가려 주세요.

보관 기간과 삭제

기기에만 저장한 데이터는 사용자가 변경·삭제하거나 앱을 삭제할 때까지 보관합니다. 설정에서 알람을 끄고 취소 결과를 확인한 후 iPhone 설정에서 앱 삭제를 선택하면 앱 저장 공간을 삭제할 수 있습니다. 앱 정리하기는 데이터를 유지할 수 있습니다. iCloud 기기 백업이나 별도로 내보낸 파일·공유받은 사본은 남을 수 있으므로 해당 서비스에서 별도로 삭제해야 합니다. 지원 이메일은 문의 처리가 끝난 후 90일 이내 삭제하는 운영 기준을 적용합니다. 그 전에도 연락처로 삭제를 요청할 수 있습니다. 법령에 따른 보관 의무가 있는 경우 그 범위와 기간에 한해 보관하고 요청자에게 안내합니다.

계정 데이터 삭제: 전체 → 내 계정 → 계정 데이터 삭제에서 시작할 수 있습니다. 삭제를 완료하면 해당 계정의 Google Drive 앱 전용 데이터 또는 Apple 계정용 서버 데이터, 본인이 작성한 분실물 글, 계정에 연결된 신고·작성자 숨김 기록, 본인이 만든 실시간 근무표 공유 링크를 지웁니다. 로그인 제공자에 대한 앱의 연결 권한을 해제하고 이전 앱 로그인 세션을 무효화합니다. Google Drive 앱 전용 데이터를 지우는 데 필요한 권한이 없으면 같은 Google 계정으로 Drive 저장을 다시 연결한 뒤 삭제를 이어서 진행해야 할 수 있습니다.

삭제를 요청한 앱에서는 해당 계정의 작업 데이터와 복원용 사본을 정리합니다. 다른 기기나 브라우저에 남은 계정별 복원용 사본은 그 환경에서 같은 계정으로 다시 로그인할 때 삭제 시각을 확인해 정리합니다. 이미 Google Calendar로 보낸 일정이나 별도로 내려받거나 공유받은 사본은 해당 기기나 서비스에서 삭제할 수 있습니다.

이전 로그인 세션이나 복원용 사본에서 삭제한 정보가 되살아나는 것을 막기 위해 서버에 삭제 기록을 보관합니다. 이 기록에는 계정 식별자에 비밀키를 적용해 만든 가명 식별값(HMAC), 삭제 처리 상태와 완료 시각이 들어갑니다. 이메일이나 삭제한 데이터의 내용은 이 기록에 포함하지 않습니다. 삭제 기록에는 별도 만료일을 두지 않습니다.

권한 철회와 개인정보 요청

iPhone 설정에서 앱에 허용한 알람·위치 권한을 철회할 수 있습니다. 계정 데이터 삭제에 도움이 필요하거나 그 밖의 개인정보 요청이 있으면 지원 이메일로 문의하세요.

공유 및 외부 서비스

백업·이미지 내보내기는 사용자가 선택한 대상에게 파일을 전달합니다. 백업에는 다른 조의 변경·메모도 포함될 수 있으므로 공유 전 확인하세요. 개발자가 근무 데이터를 판매하거나 광고·추적 목적으로 제공하지 않습니다. 이메일 지원은 Gmail을 사용합니다. 앱의 웹 화면과 지원·정책 페이지는 Cloudflare와 Vercel을 통해 제공됩니다. 이메일과 웹 요청을 처리하는 과정에서 제공업체가 이메일 내용 또는 IP 주소·요청 기록 등을 처리할 수 있으며 각 업체의 개인정보 정책도 적용됩니다. 수정이 반영되는 링크 공유를 선택하면 해당 조·월의 근무 종류를 Vercel의 접근 제한 저장소에 보관합니다. 링크를 가진 사람은 볼 수 있으며 메모·급여 정보는 포함하지 않습니다. 공유 화면에서 공유를 종료할 수 있습니다. 계정 데이터 삭제를 완료하면 해당 계정이 만든 공유 링크와 서버에 저장된 공유 근무표도 삭제됩니다.

분실물 게시판의 글은 앱 이용자에게 공개됩니다. 식단을 평가하면 식단 날짜, 끼니, 선택과 임의 식별자를 서버에서 집계합니다. 게시물의 공개 범위, 신고·삭제 방법, 보관 기간과 식단 평가의 데이터 처리는 웹 개인정보 처리방침을 참고하세요.

오늘 날씨 (선택한 지역·현재 위치)

날씨 조회에는 Open-Meteo 서비스를 사용합니다. 지역 선택값은 이 기기에만 저장하고 계정 동기화에는 포함하지 않습니다. 현재 위치는 사용자가 버튼을 눌러 권한을 허용했을 때만 조회합니다. 좌표는 소수점 둘째 자리까지 줄여 Open-Meteo에 전송하며, 현재 위치 좌표는 기기 저장소나 앱 서버에 저장하지 않습니다. 서비스 제공자는 요청 처리 과정에서 좌표와 IP 주소를 처리할 수 있습니다. 위치 권한을 허용하지 않아도 지역을 선택하여 이용할 수 있습니다. Open-Meteo 이용·개인정보 안내

통근버스 주변 노선·목적지 검색

현재 위치로 찾기를 선택하고 위치 권한을 허용하면 정류장 주변 기준점과의 직선거리를 기기에서 계산합니다. 이 기능은 현재 위치 좌표를 앱 서버에 전송하거나 계정에 저장하지 않습니다. 장소·주소를 검색하면 검색어가 앱 서버와 Photon(OpenStreetMap 기반 장소 검색)에 전달됩니다. 결과는 서버 메모리에 최대 15분 임시 보관할 수 있습니다. 선택한 위치는 기기 메모리에서만 사용하고 계정 동기화에 포함하지 않습니다. 외부 지도 링크를 누르면 해당 지도 제공자의 서비스로 이동합니다. 도보 길찾기를 선택하면 출발지·도착지 이름과 좌표가 선택한 지도 제공자(네이버 또는 카카오)에 전달되어 실제 도보 경로를 조회합니다. 길찾기를 누르기 전에는 현재 위치 좌표를 지도 제공자에게 보내지 않습니다. 위치 권한을 거부해도 주소 검색과 전체 노선 보기를 이용할 수 있습니다.

주차장 현황

iPhone 앱에서는 주차장 현황을 조회할 수 있습니다. 만차 알림과 연동된 주차장 제보는 Safari 홈 화면에 추가한 웹앱에서 이용할 수 있습니다. 웹앱의 주차장 제보와 위치 정보 처리는 웹 개인정보 처리방침에서 확인할 수 있습니다.
