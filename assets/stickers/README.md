Original SVG food stickers created for 교대 루틴.

Visual direction: simple filled silhouettes, rounded shapes, warm food colors and two-tone shading, inspired by the Icons8 Color food collection: https://icons8.kr/icons/set/food--style-color

All SVG files in this folder are original project artwork, not downloaded Icons8 assets. Existing meal-tab Icons8 PNGs are unchanged.

The pork-belly replacement and seven additional Korean dishes are original vector drawings referencing the user-provided food sheet (2026-10-26). Jjamppong extends the same outlined, earthenware/plate visual style.
